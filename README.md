# GuoDong World Clock · 国动 世界时钟

面向跨国协作的“先看一眼，再决定是否联络”时间面板。展示国动集团本部（北京）、哈萨克斯坦国动（阿拉木图）和俄罗斯国动（莫斯科）的当地时间、办公状态与共同在岗窗口。

**在线访问：** <https://lyon-lyon-lyon.github.io/GuoDong-WorkingHours/>

## 覆盖范围

| 单位 | 城市 | IANA 时区 | 相对北京 | 当地工作时间 |
|---|---|---|---|---|
| 国动集团本部 | 北京 | `Asia/Shanghai` | 基准 | 09:00–17:30 |
| 哈萨克斯坦国动 | 阿拉木图 | `Asia/Almaty` | 晚 3 小时 | 09:00–18:00 |
| 俄罗斯国动 | 莫斯科 | `Europe/Moscow` | 晚 5 小时 | 09:00–17:30 |

三地午休均为当地时间 12:00–13:00。莫斯科为固定城市，不再提供城市选择器。

## 核心功能

- **现在能否联络**：顶部主卡片直接回答是否可以发起联络，并给出三地当地时间、当前共同窗口和下一个共同窗口。
- **真实共同窗口**：把三地工作时间统一换算到北京时间后逐段求交，自动扣除各地午休；不是简单展示对方单方面的工作时段。
- **周末与休息日**：按当地时间判断周一至周五；周末显示“周末休息”，不会误报“可直接联络”。`PLACES[*].holidays` 已预留法定节假日集合，当前为空。
- **三地工作轴**：以北京时间 06:00–24:00 展示三地在岗、午休和共同在岗区间，并标出当前时间。
- **三只实时钟表**：模拟表盘与 24 小时数字时间，秒级刷新；哈萨克斯坦和俄罗斯秒针同样正常更新。
- **真实天象**：天空与地球仪按 UTC 时刻、城市经纬度和太阳位置推算，包含真实太阳赤纬、晨昏线和月相方向。
- **时区筛选**：隐藏哈萨克斯坦或俄罗斯后，速览、状态卡和时间轴同步联动；北京始终显示。
- **移动端可用**：地球仪与文字上下布局；时间轴可横向滑动，并支持键盘聚焦后滚动。
- **可访问性**：语义化标题、可见状态提示、`aria-live` 联络结论、对比度达标、`prefers-reduced-motion` 降级。

## 联络判定口径

### 单地状态

| 状态 | 判定条件 | 页面文案 |
|---|---|---|
| 周末休息 | 当地周六或周日 | 周末休息 |
| 休息日 | 日期在 `holidays` 中 | 休息日 |
| 未上班 | 工作日、早于 09:00 | 未上班 |
| 办公中 | 09:00–12:00 或 13:00–下班 | 办公中 |
| 午休中 | 当地 12:00–13:00 | 午休中 |
| 已下班 | 工作日、晚于下班时间 | 已下班 |

### 共同窗口

1. 将每个地区的当地时间工作窗口拆成“上午”和“下午”两段。
2. 用 `(8 − 当地 UTC 偏移) × 60` 换算到北京时间。例如阿拉木图 11:30 对应北京 14:30。
3. 对北京、阿拉木图、莫斯科的工作窗口逐段求交，得到三地共同在岗窗口。
4. 页面在接下来的 3 天内以 5 分钟步长寻找下一个共同窗口；周一至周五的当前结果为 `14:00–15:00` 与 `16:00–17:00`（北京时间）。

当前偏移由浏览器内置 IANA 时区数据库通过 `Intl.DateTimeFormat` 推导。三地目前均不实行夏令时；若未来时区规则变化，页面会随浏览器时区数据库更新。

### 当前限制

- 法定节假日未内置，只预留了按日期维护的 `holidays` 集合。
- 以固定 5 分钟粒度搜索窗口，适合联络决策，不用于考勤结算。
- 地球仪是正交投影的仪表盘视图，不是完整地理信息系统。

## 技术实现

- 纯原生 HTML / CSS / JavaScript，运行时单文件、零外部依赖，可离线打开。
- `PLACES` 是唯一配置源：名称、IANA 时区、经纬度、工作时间、午休、工作日、节假日和颜色都从这里派生。
- 天空使用 Meeus/NOAA 低精度太阳位置与 Meeus 第 47 章低精度月球位置。
- 地球仪使用正交投影、太阳赤纬/赤经、格林尼治平恒星时和晨昏线求解；观察视角限制在 ±22° 的低幅往返漂移，避免三地长时间转出可见半球。
- 秒针 100 ms 刷新；天空、状态与时间轴 30 秒刷新；地球仪 5 秒刷新。页面隐藏时暂停定时器，恢复可见时立即重算。

## 本地使用

直接双击 `index.html` 即可，不需要安装依赖。推荐使用较新的 Chrome、Edge、Firefox 或 Safari。

## 开发与测试

运行时不需要 Node.js；只有开发和自动化测试需要：

```bash
npm install
npx playwright-core install --with-deps chromium
npm test
```

在 Windows 上也可以复用已安装的 Edge：

```powershell
$env:CHROME_PATH = "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe"
npm test
```

测试覆盖：

- 周一 14:30 三地共同在岗、下一窗口与秒针刷新
- 06:30 / 12:30 / 17:30 / 22:00 边界状态
- 周六“周末休息”与下一工作日窗口
- 隐藏哈萨克斯坦 / 俄罗斯后的联动
- 390px 移动端无横向溢出、时间轴可滚动且可聚焦
- axe WCAG 2.1 A/AA 自动检查

GitHub Actions 在每次 push 和 pull request 时执行同一套测试。
