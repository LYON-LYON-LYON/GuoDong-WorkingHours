# GuoDong World Clock · 国动 世界时钟

面向跨国协作的“先看一眼，再决定是否联络”时间面板。展示国动集团本部（北京）、哈萨克斯坦国动（阿拉木图）和俄罗斯国动（莫斯科）的当地时间、办公状态、共同在岗窗口与本月日历。

**当前版本：1.2** · **在线访问：** <https://lyon-lyon-lyon.github.io/GuoDong-WorkingHours/>

## 覆盖范围

| 单位 | 城市 | IANA 时区 | 相对北京 | 当地工作时间 |
|---|---|---|---|---|
| 国动集团本部 | 北京 | `Asia/Shanghai` | 基准 | 09:00–17:30 |
| 哈萨克斯坦国动 | 阿拉木图 | `Asia/Almaty` | 晚 3 小时 | 09:00–18:00 |
| 俄罗斯国动 | 莫斯科 | `Europe/Moscow` | 晚 5 小时 | 09:00–17:30 |

三地午休均为当地时间 12:00–13:00。莫斯科为固定城市，不再提供城市选择器。

## 核心功能

- **现在能否联络**：顶部主卡片直接回答是否可以发起联络，并给出三地当地时间、当前共同窗口和下一个共同窗口。
- **真实共同窗口**：把三地工作时间统一换算到北京时间后逐段求交，自动扣除各地午休；不是简单展示对方单方面的工作时段。
- **三国本月日历**：顶部左侧保留当前太阳方位，右侧并排显示北京、阿拉木图、莫斯科的当地时间月历；每国按自己的当地日期决定“今天”和所在月份。
- **周末、节假日与调休**：周末使用灰色底，法定节假日使用暖色底，调休上班使用蓝色底，今天使用深色圆环；月历下方直接列出当月节假日与调休日期。
- **节假日进入业务判断**：法定节假日显示为休息日；中国调休上班日在周六、周日也按工作日判断；三地共同窗口自动跳过节假日并认可调休工作日。
- **三地工作轴**：以北京时间 06:00–24:00 展示三地在岗、午休和共同在岗区间，并标出当前时间。
- **三只实时钟表**：模拟表盘与 24 小时数字时间，秒级刷新；哈萨克斯坦和俄罗斯秒针同样正常更新。
- **真实天象**：天空与地球仪按 UTC 时刻、城市经纬度和太阳位置推算，包含真实太阳赤纬、晨昏线和月相方向。
- **时区筛选**：隐藏哈萨克斯坦或俄罗斯后，速览、状态卡、月历和时间轴同步联动；北京始终显示。
- **移动端可用**：地球仪与文字上下布局；月历和时间轴可横向滑动，并支持键盘聚焦后滚动。
- **可访问性**：语义化标题、可见状态提示、`aria-live` 联络结论、对比度达标、`prefers-reduced-motion` 降级。

## 联络判定口径

### 单地状态

| 状态 | 判定条件 | 页面文案 |
|---|---|---|
| 调休上班 | 日期在 `workdayOverrides` 中，优先于周末和节假日 | 按当天时间显示未上班 / 办公中 / 午休中 / 已下班 |
| 周末休息 | 当地周六或周日，且不是调休上班日 | 周末休息 |
| 法定节假日 | 日期在 `holidays` 中 | 显示节假日名称，例如“国庆节” |
| 未上班 | 工作日、早于 09:00 | 未上班 |
| 办公中 | 09:00–12:00 或 13:00–下班 | 办公中 |
| 午休中 | 当地 12:00–13:00 | 午休中 |
| 已下班 | 工作日、晚于下班时间 | 已下班 |

### 共同窗口

1. 将每个地区的当地时间工作窗口拆成“上午”和“下午”两段。
2. 用 `(8 − 当地 UTC 偏移) × 60` 换算到北京时间。例如阿拉木图 11:30 对应北京 14:30。
3. 对北京、阿拉木图、莫斯科的工作窗口逐段求交，得到三地共同在岗窗口。
4. 页面在接下来的 14 天内以 5 分钟步长寻找下一个共同窗口，足以跨过春节、国庆等连续假期；普通工作日的当前结果为 `14:00–15:00` 与 `16:00–17:00`（北京时间）。

当前偏移由浏览器内置 IANA 时区数据库通过 `Intl.DateTimeFormat` 推导。三地目前均不实行夏令时；若未来时区规则变化，页面会随浏览器时区数据库更新。

## 节假日数据（2026）

节假日数据静态内置在 `index.html`，运行时不请求外部 API，断网也能使用。每周、每月和每日状态共用同一份配置，避免“日历上标了休、联络判断却还在上班”的割裂。

| 国家 | 覆盖内容 | 数据口径 | 来源 |
|---|---|---|---|
| 中国 | 元旦、春节、清明、劳动节、端午、中秋、国庆，以及 6 个调休上班日 | 国务院办公厅 2026 年放假安排 | [中国政府网](https://www.gov.cn/zhengce/zhengceku/202511/content_7047091.htm) |
| 哈萨克斯坦 | 新年、东正教圣诞节、妇女节、纳吾鲁孜节、人民团结日、祖国保卫者日、胜利日、古尔邦节、首都日、共和国日、独立日及补休 | 法定节假日 + 周末顺延补休 | 哈萨克斯坦劳动法及 2026 年日历数据 |
| 俄罗斯 | 新年假期、东正教圣诞节、祖国保卫者日、妇女节、劳动节、胜利日、俄罗斯日、民族团结日及调休 | 2026 年生产日历 | [Consultant.ru 2026 生产日历](https://www.consultant.ru/law/ref/calendar/proizvodstvennye/2026/) |

数据结构：

```js
holidays: new Map([
  ["2026-10-01", "国庆节"]
]),
workdayOverrides: new Set([
  "2026-10-10"
])
```

- `holidays` 保存“日期 → 节假日名称”，用于月历标记、休息日判断和文案。
- `workdayOverrides` 保存中国调休上班日；其优先级高于周末和节假日。
- 新增年份时更新 `HOLIDAY_RANGES`、`WORKDAY_OVERRIDES` 和 `CALENDAR_DATA_YEAR`，再补边界测试。

## 当前限制

- 节假日静态覆盖 2026 年；打开 2027 年日期时，月历仍显示周末，但节假日在维护前不会显示。
- 以固定 5 分钟粒度搜索窗口，适合联络决策，不用于考勤结算。
- 地球仪是正交投影的仪表盘视图，不是完整地理信息系统。

## 技术实现

- 纯原生 HTML / CSS / JavaScript，运行时单文件、零外部依赖，可离线打开。
- `PLACES` 是唯一配置源：名称、IANA 时区、经纬度、工作时间、午休、工作日、节假日、调休日和颜色都从这里派生。
- 天空使用 Meeus/NOAA 低精度太阳位置与 Meeus 第 47 章低精度月球位置。
- 地球仪使用正交投影、太阳赤纬/赤经、格林尼治平恒星时和晨昏线求解；观察视角限制在 ±22° 的低幅往返漂移，避免三地长时间转出可见半球。
- 秒针 100 ms 刷新；天空、状态、月历与时间轴 30 秒刷新；地球仪 5 秒刷新。页面隐藏时暂停定时器，恢复可见时立即重算。

## 本地使用

直接双击 `index.html` 即可，不需要安装依赖。推荐使用较新的 Chrome、Edge、Firefox 或 Safari。

## 开发与测试

运行时不需要 Node.js；只有开发和自动化测试需要：

```bash
npm install
npx playwright-core install --with-deps chromium
npm test
```

在 Windows 上也可以复用已安装的 Edge：

```powershell
$env:CHROME_PATH = "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe"
npm test
```

测试覆盖：

- 周一 14:30 三地共同在岗、下一窗口与秒针刷新
- 06:30 / 12:30 / 17:30 / 22:00 边界状态
- 周六“周末休息”与下一工作日窗口
- 三列本月日历、当地“今天”、周末与俄罗斯 11 月节假日
- 国庆节休息、中国调休上班日，以及跨 7 天长假的下一个共同窗口
- 隐藏哈萨克斯坦 / 俄罗斯后的状态、月历与时间轴联动
- 390px 移动端无横向溢出、月历与时间轴可滚动且可聚焦
- axe WCAG 2.1 A/AA 自动检查

GitHub Actions 在每次 push 和 pull request 时执行同一套测试。
