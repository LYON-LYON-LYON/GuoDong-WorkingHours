# GuoDong World Clock · 国动 世界时钟

国动集团本部与哈萨克斯坦国动、俄罗斯国动的跨国联络时间对照网页。

**在线访问：** <https://lyon-lyon-lyon.github.io/GuoDong-WorkingHours/>

## 覆盖范围

| 单位 | 城市 | 时区 | 与北京时差 |
|---|---|---|---|
| 国动集团本部 | 北京 | 东八区（UTC+8） | 基准 |
| 哈萨克斯坦 | 阿拉木图 | 东五区（UTC+5） | 晚 3 小时 |
| 俄罗斯 | 莫斯科 | 东三区（UTC+3） | 晚 5 小时 |

## 功能

- **联络速览板**：标题下方直接给出三地当地时间、相对北京的时差、当前办公状态徽标（办公中 / 午休中 / 未上班 / 已下班），并给出"此刻能否联络、下一窗口何时可联络"的结论
- **真实天象驱动的天空**：按各城市经纬度与 UTC 时刻实时推算太阳高度角与方位角，驱动天空配色、日轮位置与月相
- **实时钟表**：北京时间、哈萨克斯坦时间、俄罗斯时间，模拟表盘 + 24 小时制数字时间，秒级刷新
- **时区筛选**：可单独隐藏哈萨克斯坦或俄罗斯时间，速览板同步联动
- **跨时区上班时间轴**：以北京时间轴（06:00–24:00）并列展示三地工作时段与当地午休



## 天象计算说明

天空效果不是按固定时段切换渐变，而是由真实太阳位置驱动：

| 环节 | 实现 |
|---|---|
| 时间基准 | 仅使用 UTC 时刻 + 城市经纬度，与服务器时区、浏览器时区无关 |
| 太阳位置 | Meeus/NOAA 算法：几何黄经 → 赤纬/赤经，格林尼治平恒星时求时角，得到高度角与方位角 |
| 月亮位置 | Meeus 第 47 章低精度黄道坐标，含真实月相与照亮比例 |
| 昼夜阈值 | 高度角 > +6° 白天；−6°～+6° 晨昏；−18°～−6° 暮色；< −18° 黑夜 |
| 极地降级 | 正午与午夜高度角同时高于/低于地平线时，判定为极昼/极夜并固定对应天色 |
| 刷新机制 | 时钟走针 100ms，天象 30s（配 1.2s CSS 过渡平滑）；页面从后台恢复时立即重算 |

精度经不变量校验：太阳正午 UTC 与理论值（12:00 − 经度/15 − 均时差）偏差 ≤0.4 分钟，春分全球昼长 12.00 小时，夏至赤纬 23.44°。

## 上班时间口径

| 单位 | 当地时间 | 午休 |
|---|---|---|
| 国动集团本部（北京，东八区） | 09:00–17:30 | 当地 12:00–13:00 |
| 俄罗斯国动 | 09:00–17:30 | 当地 12:00–13:00 |
| 哈萨克斯坦国动（东五区） | 09:00–18:00 | 当地 12:00–13:00 |

共同在岗时段由页面实时计算得出，随俄罗斯所选城市自动更新。时间轴以北京时间轴（06:00–24:00）呈现，仅显示各公司各自的当地在岗时段与午休；显示的时区可在上方筛选开关中切换，本模块随之联动。

## 联络状态判定

速览板的办公状态按各地**当地时间**判定，与浏览器所在时区无关：

| 状态 | 判定条件 | 提示语 |
|---|---|---|
| 办公中 | 当地 09:00–12:00 或 13:00 至下班 | 双方同时在岗，可直接联络 |
| 午休中 | 当地 12:00–13:00 | 午休中，13:00 后可联络 |
| 未上班 / 已下班 | 办公窗口之外 | 给出下一个双方同时在岗的北京时间窗口 |

## 使用方式

无需安装依赖，双击 `index.html` 即可离线打开。页面为单文件实现，不依赖任何外部网络资源，时区数据由浏览器内置 IANA 时区库计算。

## 技术说明

- 纯原生 HTML / CSS / JavaScript，单文件无依赖
- 时间计算基于 `Intl.DateTimeFormat` 与浏览器内置时区数据库
- 联络状态按当地时间的办公窗口判定，并推算双方同时在岗的窗口

## 更新

直接修改 `index.html` 后提交，或使用 API 部署脚本推送至 `main` 分支。
